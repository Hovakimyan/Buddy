# Buddy marketing website
Buddy is a Mac companion for Claude Code, displaying session state and permission requests around the notch. Block is its expressive blue character. Buddy never approves automatically; unanswered requests return to the terminal. An optional iPhone companion uses private iCloud and requires signed builds and the same Apple Account; real-device verification is still pending. Codex and other agents are planned. The app is a development preview, with source and setup instructions; repository access may be required. No public signed release or App Store listing exists yet.

Audience: developers using Claude Code on macOS. Make the companion understandable through an interactive sample, then lead to source and installation instructions.

User direction: replace the conventional landing page with a creative, interactive experience. Concept: a miniature leave-your-desk adventure: Mac session, request, optional phone handoff, visitor decision. Demonstrations must be identified as simulations. Preserve blue Block character and honest availability.
